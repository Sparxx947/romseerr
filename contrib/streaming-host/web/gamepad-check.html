So geht es:
1. Diese Seite anklicken, damit sie den Fokus hat.
2. Eine Taste am Controller drücken. Die Gamepad-API meldet aus Datenschutzgründen nichts, bevor das passiert ist — ein angeschlossener, unberührter Controller ist für den Browser unsichtbar.
3. Erscheint hier nichts, kommt das Pad nicht bis in den Browser. Dann hilft kein Blick in den Streaming-Host — dort kann nichts ankommen, was hier nicht ist.
How to: click this page so it has focus, then press a button. The Gamepad API reports nothing until a button is pressed. If nothing appears here, the pad is not reaching the browser and nothing on the streaming host can help.
